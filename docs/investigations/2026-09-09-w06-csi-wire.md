## 时间与代次

源码核对确认原资源层用相邻 32-bit driver timestamp 推测 wrap，无法区分长空窗
中的多次回绕；旧 effective.timestampAccuracy 却按 power-save 状态报告 normal
或 power-save-dependent。这是与 W-06 契约的差异，尚无本批实机故障复现证据。

现在在 CSI callback 入口取一次 esp_timer 单调时间，target normalize 后写入
metadata.timestamp_us，资源层直接保存并用于 rate filter；删除 driver epoch
猜测函数和对应资源字段。raw driver timestamp 仍保留为原始字段，不用它推算时间。
公开 Frame/Batch info 与 status 增加/更新 timestampAccuracy=callback-time，wire
accuracy=2。没有宣称 RF 到达精度或 UTC，也不因 modem sleep 配置变化提升精度。

原 get_channel/lease_channel_status 的 generation 是 channel revision，不能写作
physical Radio generation。启动和 status refresh 现在取精确 Radio lease generation；
callback 将其复制进每帧 metadata，新 Frame info 和 wire 使用这份保留值。旧 Frame
跨 Session close 后不会跟随其他 owner 的 driver restart 改变代次。CSI 清理仍先
排空 callbacks_active，再释放 Radio；未把 driver 操作搬进临界区。

## CSI snapshot 与 Source

CSI snapshot 复制可用 MAC/RSSI/channel/PHY/validity 与 callback 时间，规范化 native
CSI unknown PHY 为 wire 255。layout 指针借用原 slot，调用方必须在完成编码前
持有该 slot 的精确 owner；snapshot 不是新的 owner。输出禁止覆盖 slot，预检失败
不写输出。没有 packet 采集时不从 mac/dmac 或 RX 字段伪造 packet span、header、
FCS、driver payload/packet report 或其 availability。

Batch Source 先 retain 原 events，对所有 slot 建立有界 frame descriptor 并预检。
临时 descriptor array 在生成控制区后释放；metadata 逐帧直接填入控制区，不复制
大块 CSI payload。control allocation 使用统一 checked dimensions，known length
保留包含 final padding 的总长度。

迭代顺序为 control、每帧原 CSI span、0–3 字节显式零 padding，包括最后一帧。
丢失已保留 slot 会抛出异常，不静默跳过数据；非法 snapshot 使用
WIFI_CSI_INVALID_DATA，真正分配失败仍返回 OOM。构造失败释放本次所有 retain；
iterator close/cancel 和 Source 在迭代期间被销毁的既有延迟释放政策继续保留。

单帧 frame.source() 当前仍是原始 samples Source；新的单帧统一 wire API 与
sampleSource 命名还需随 W-05 公共接口完成，未提前添加占位类型。

## Host 与 v1

新增共享 decoder `scripts/esp32qjs_rx.py`，CSI CLI/parse_batch 通过它解析。显式
kind 区分 CSI/Monitor magic 和目录大小，同一 metadata 校验器覆盖两种格式。
结果为 RxBatch/RxFrame/RxMetadata，CSI 与 packet 各有独立 memoryview；调用方
必须保持可变输入稳定。旧 CsiMetadata/CsiProtocolError 和 payload 命名直接替换，
没有别名、兼容 reader 或另一版本。设备代码、类型、API 文档和固定 hex fixture
同步，旧 24/16/192 格式拒绝。

校验包括 count 上限、uint32 加法/对齐、精确总长度、canonical offsets、所有
reserved/unused slots、未知 flags/enums、optional scalar/address/header/report
的规范值、目录重复字段、捕获/header/parse/pointer 关系，以及 CSI encoding、
segment/range/IQ 和 trailing padding。Host 不推导 UTC、driver epochs、FCS 或 RF
质量。Monitor 解码基础不等于其公开 Source 或 PCAPNG exporter 已实现。
