# W-03：有界公共 MAC header parser

## 当前实施范围

新增内部 `esp32_mquickjs_wifi_rx.h` 与 `wifi_common/esp32_mquickjs_wifi_rx.c`。
它们属于后续 Monitor/CSI/Raw TX 共用的生产解析实现，已加入组件构建。
本批没有公开 wifi.monitor，也未注册原始包 callback 或修改 CSI 开关政策。
当前 CSI 只通过 Radio 持有独占 promiscuous enable lease；其 CSI callback 与
原始包 RX callback 是不同入口，不能把现状描述成已有共享 packet broker。

parser 的输入是调用者已经证明可读的 MAC 字节跨度与独立 output。SDK sig_len
不是通用 allocation/readable length，不能直接套用；MISC/metadata-only callback
的 payload 长度为零。后续 target adapter 必须先证明指针布局，再调用 parser。
固定 SDK 依据：esp_wifi.h 的 wifi_promiscuous_cb_t 注释与
esp_wifi_types_generic.h 的 wifi_promiscuous_pkt_type_t 注释。

## 已实现的解析边界

- 有界复制 Frame Control、Duration/ID、Sequence Control、QoS Control 和 HT
  Control，显式按 little endian 读取，不做未对齐结构体指针转换。
- 版本 0 的已审查 Management/Data/Control MAC header：Addr4、QoS、HT Control，
  ACK/CTS 短头、Control Wrapper（无 TA）、PS-Poll、RTS、BAR/BA、CF-End 等。
- 使用 DS 组合区分 source/destination/TA/RA/BSSID；WDS 的 BSSID 不可用，
  ACK/CTS/Control Wrapper 的发送端不可用。PS-Poll 的 BSSID 来自 RA，CF-End
  来自第二地址。
- 先算完整头长，再进行地址/sequence/QoS/HT 读取。短输入只保留可证明的 FC/
  Duration 和所需头长；没有完整头部时不发布地址或可选控制字段。
- 未知版本、保留 subtype、扩展布局与不合法的 Management/Control DS flags
  分别给出内部 parse status。未知布局不猜测为 24 字节。
- 输入长度 0、1、NULL/nonzero、输出 NULL 都显式处理。失败清空旧输出字段，
  不修改原始输入，也不保留 SDK/input 指针。

头长和 DS 地址角色对照了固定
[Linux v6.12 wireless util 实现](https://raw.githubusercontent.com/torvalds/linux/v6.12/net/wireless/util.c)，
Control 的 RA/TA/PS-Poll/BAR 结构对照了
[Linux v6.12 IEEE 802.11 定义](https://raw.githubusercontent.com/torvalds/linux/v6.12/include/linux/ieee80211.h)。
新 parser 独立实现可读跨度检查与结果契约，不引入 Linux 代码依赖。

`PARSED` 只证明该 MAC header 的结构读取成立，不证明完整帧体、加密/安全策略、
IE/Action 内容、FCS、A-MSDU 子帧或 Mesh 逻辑地址语义。BAR/BA 的可变字段属于
帧体，不冒充普通 MAC Sequence Control。protected body 保持 opaque。FCS
是否存在、是否可信及实际 payload/captured length 仍由后续 target/wire 层完成。

## 生产路径测试源码（not-run）

`tests/c/unit/wifi/monitor/test_wifi_rx_header.c` 链接实际生产 C 单元，没有独立的测试 parser。

- golden case：四种 DS 地址映射、Management、短 Control、PS-Poll、CF-End、
  Control Wrapper；Addr4/QoS/HT 的准确偏移、所需头长、little endian 值。
- 每种已选头部的恰好够长/差一字节；未知版本/类型/subtype、非法 DS flags、
  NULL 与零长度、protected QoS MAC header，失败后不遗留上次地址。
- 使用 mmap/mprotect 的末尾不可读保护页，对全部 65536 个 FC 位组合逐一检查
  0–64 字节跨度（含奇数未对齐地址）；边界后的访问会 fault，输入快照检查写入。
  这是待运行的内存读取范围测试，不把列出组合数量写成通过证据。
- CMake 已登记 Host C target，但本批没有编译或运行该 test executable。
