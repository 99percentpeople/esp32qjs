## 契约与捕获

sole v1 的 raw config 改用 `pmf: "disabled" | "optional" | "required"`，直接替换
旧 pmfRequired 布尔字段，没有兼容别名。正式类型、reviewed field mapping、生成
C 字段白名单和 schema 文档同步更新。SDK capable 仍是 derived 字段：普通 setter
忽略它的 false 输入，所以 disabled 必须配合专用 SDK 操作；不会把 ABI 字段赋值
当成已完成关闭。

raw capture 直接将 pmf 交给共用 Station/AP parser，删除旧布尔转换分支。Station
parser 仅在 configure 操作中接受 disabled，随后通过纯值共享 validator 核对 auth
与 disableWpa3CompatibleMode。共享 validator 不调用 SDK、不获取 owner，并拒绝
无效 interface/null config 和禁用构建中的 AP。直接 connect 仍拒绝 disabled，
其运行中生命周期尚未提供合法的配置/停止/启动协调。

纯 WPA3/OWE 的 Station PMF 默认 required；显式 weaker policy 在 mutation 前拒绝。
关闭要求已审查的非 WPA3 family，Station 还要求 disableWpa3CompatibleMode=true，
沿用该参数的现有 build gate。没有偷偷切换 auth 或 compatible policy 以迎合请求。
AP 沿用刚完成的 disabled 条件、PMF/SAE 冲突和读回规则。

## 原生事务

停止后的复合配置事务在分配快照或 SDK mutation 前分别校验 Station/AP disabled
条件；每个配置写入后若请求 disabled，就执行所选接口的专用 disable_pmf_config，
再作既有配置读回、controls 重放及最终读回。START 仍发生在事务接受后。
新增 Station 阶段 station-pmf-security / station-pmf-config，AP 阶段保留。

错误继续进入已有 RAM rollback、原 PMF 恢复和 cleanup 后缀；不以 setter 失败
推断未修改，不影响未请求的接口，也不把 RAM 回滚写成 NVS 恢复。共享 PMF
validator 同时由独立 Driver、恢复 helper 和 capture 使用，避免两套安全规则。
没有新增常驻账本或 heap 结构。
