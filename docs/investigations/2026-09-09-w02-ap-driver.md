## 契约与生产路径

WiFiAccessPointOptions.driver 使用 `Partial<Omit<WiFiAccessPointDriverConfig, "ssid">>`。
SSID 必须在顶层；两层必须是 plain options，未知键、嵌套 driver/ssid 和 NUL 后缀
拒绝。defined 字段只允许出现在一层，即使值相等也报错；undefined 视为缺省。
顶层 beaconIntervalMs 与 driver.beaconIntervalTu 是同义字段，重复同样拒绝。

顶层 beaconIntervalMs 保留向上取整到 100 TU 的契约；嵌套 beaconIntervalTu 使用
100..60000 的整数且必须为 100 的倍数，直接写 native TU，不经浮点毫秒往返。
顶层 channel 保留 1..11、默认 1；嵌套 channel 接受 0..14 或 target 支持的标准
5 GHz channel，再由完整原生 validator 和现有事务检查 target、country、band 与
生命周期条件。0 交给 SDK 选信道，不承诺最终使用哪个频道或能够共享重开。
嵌套空密码沿用 raw configure 的 absent 语义；最终 auth 仍须允许空凭据，顶层
空密码继续拒绝。没有把嵌套输入当作绕过安全或共享 Radio 的通道。

生产 capture 从生成的 AP raw 字段表构建两层白名单，逐值捕获到受 GC root 保护
的临时普通对象。现有完整 AP parser 校验合并后的认证/PMF/SAE/idle 等依赖；
原始 channel/TU 在有界整数校验后直接赋值，最后再次调用完整原生 AP validator。
只有最终成功的配置进入已有 shared reopen 或 stopped configuration executor。
未改变 driver 事务、PMF dedicated 操作、读回、AP_START 或失败 cleanup 的交接。

临时密码转换缓冲区和失败 native config secure-zero；所有临时 roots 在 capture
结束时释放。无新增常驻状态或原生 owner。类型、capabilities.accessPointOptions.driver、
API 文档和 02 任务书同步。SoftAP-disabled 时不编译该 capture，capability 为 false；
相关禁用构建的实际链接验收仍待集中进行。
