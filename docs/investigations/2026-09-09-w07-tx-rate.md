## SDK 与公共契约

固定 SDK `components/esp_wifi/include/esp_wifi.h:1577–1605` 明确两个 802.11 rate
setter 均要求 init 后、start 前；旧 rate-only setter 不支持 11A/11AC/11AX。
实际使用 `esp_wifi_config_80211_tx`，没有对应公开 getter。不使用 private fixed-rate
接口，也不假定任何 target/band/interface 的默认速率为 1 Mbps。

`wifi.driver.configureTxRate(iface, {phy,rate,ersu?,dcm?})` 与
`wifi.driver.txRateStatus(iface)` 已注册；正式类型、manifest、API 文档和 SDK map
同步。其余 driver 草案仍不进入注册表。配置精确枚举名/严格 boolean、unknown keys
及 NUL 后缀验证在 driver mutation 前完成，getter 各读取一次并保留原始异常。
目标 PHY gate 与速率枚举来自 SDK，尤其 HE target 的 MCS8/9 会改变 SGI enum 值，
不通过 ordinal 算术推断速率。最终 SDK 仍验证 PHY/protocol/band/ERSU/DCM 组合。

只读状态返回框架记录，source 仅在 known 时为 framework-write；不是 SDK readback，
不是 RF 速率或对端 ACK 证据。API 的完整状态/错误字段见 [driver 文档](../api/wifi-driver.md)。

## 原生边界与恢复

纯 C helper 通过可注入 writer 调用生产 SDK 边界。Radio operation mutex 覆盖
准入、写入、回滚与记录发布，SDK 不进入 IRQ critical section。写入要求 initialized、
fully stopped、无 Radio lease/wake lock/operation/lifecycle/promiscuous owner；没有
隐式 init/stop 或修改其他 owner 的配置。configure(start:false) 仍可能持有 application
lease，调用方须完成 stop 释放所有 owner。

成功写入记录 target config、Radio generation 与 boot-scoped write identity。
失败只在同代已知前值存在时重写前值；即使恢复成功也返回原始失败。恢复失败记录
独立 rollbackError；没有可信前值或无法恢复时 known=false/uncertain=true，设置
status.radio 的 tx-rate-uncertain 故障，阻止新 owner 启动。

显式 configure 可以在同样 stopped/零 owner 条件下修复本边界自己的速率故障；不能
绕过其他 lifecycle/driver 故障。所有接口 uncertainty 消除后才清除此 rate 故障。
首次未知不等于失败 uncertainty，未曾显式写入的接口不会阻止普通默认行为。
成功 physical deinit 才清空记录；stop 不清除。deinit 的后续 callback drain 失败
不会重复 deinit 或恢复旧记录。identity 永不回绕，耗尽在 SDK 前拒绝。

JS conversion 在释放 Radio mutex 后完成，OOM 不会撤销已被 driver 接受的配置；
调用方可查 txRateStatus 再决定后续动作。原生静态记录无 JS/runtime/payload 指针。
临时 Raw TX rate lease、native fault recovery 和 restart 重放仍待实现；本批仅建立
已知前值与排他显式写入基础，没有将 rateLease capability 提升为 true。
