# W-08：EAP Radio 借用记录与 runtime 退出门槛

基线 firmware `d7db8d1`、SDK `fff9895c82d744c7237be8847347bdd1b07c6643`。
接续 [原生安装事务](2026-09-10-w08-eap-install.md)。本轮把原生 SDK binding
接入 Radio 及 runtime 退出流程，公开 enterprise API 尚未接入。

## 实现与边界

EAP 需要跨越连接过程持有凭据，所以不占用原有 scan/connect operation 槽。
Radio 新增独立记录：安装 identity、Radio generation、application/STA/AP 精确
lease identity 和 ready 状态；全部在既有 operation mutex 内访问，没有在
critical section 中执行 driver/SDK 调用。

- 安装复用 connection owner 检查，要求运行中的 STA 或 APSTA、helper 空闲且
  未连接、没有其他原生 owner。实际 get_ap_info 只接受 NOT_CONNECT；其他错误
  原样保留，不当作未连接。APSTA 固定三个现有 owner，STA-only 可没有 application。
- mutex 串行覆盖准入、SDK 安装及借用登记。安装失败仍可能返回 retained binding，
  此时保留其 identity/generation/lease，ready=false，不可通过释放 lease 丢弃责任。
- 有 binding 时拒绝新增 lease、释放被固定的 helper lease、生命周期准入和物理
  STOP/shutdown。成功安装仍允许现有 STA 正常 scan/connect；安装或清理故障时
  ready=false，拒绝新连接操作和有副作用的 connection 控制。
- clear 校验完整 identity/generation 和仍存活的 helper lease，等待其他 operation
  排空，确认 STA 未连接，才调用原生清理。只有 entered、SDK snapshot 已观察且
  资源为零、安装层已归还借用，才清除 Radio 记录。SDK dispatch 失败后返回值
  仍显示 retained identity；旧/重复 token 不可释放新 binding。
- runtime destroy 在 Future prepare 后、最终 drain gate 和 helper/VM 释放前
  推进 EAP 清理。复用现有 disconnect epoch、投递/迟到事件、IP fence 和 idle
  判断，先完成断连与复用屏障，再清理凭据。失败返回 false，保留 runtime 和
  Radio 记录供下一次清理；空闲时不发起断连或 SDK 调用。

当前准入明确要求排他 helper 集合，尚未支持 enterprise 与 Monitor/Raw TX/
ESP-NOW 等新增 owner 共存。公开 configure/disable/stop/restart 如何管理配置
和借用、JS Future/GC capture、企业认证 status/error 以及完整共存策略仍待完成。
原生 clear 不隐式断连；runtime prepare 才沿现有 helper 流程请求断连。
不能把 helper 记录等同所有外部 SDK 调用都被纳入所有权，也不能把驱动状态
不可读时的故障恢复描述为已完成。

## 验证

C5 roaming-enabled 与 Wi-Fi-disabled immutable Context 构建、manifest 52/504、
feature 27、SDK schema STA35/AP21、strict TS、MQuickJS 61/59 和 SDK map 检查通过。
仅 ESP-NOW（Wi-Fi 关闭）Context 也构建通过，最终 ELF 未包含 EAP 清理入口。
新增 runtime 清理引用使 EAP 的清理/安装内部实现进入最终 ELF；公开激活入口仍
未注册。实际 symbol、SDK/installer archive hash、binary 大小及跟踪静态对象
见 `build/w08-eap-radio-evidence.json`。编译和链接均不是实际认证/退出运行证明。
启用镜像 2,940,896 bytes，较上批增加 44,656 bytes；Wi-Fi 关闭镜像 459,024 bytes
不变。新增 Radio 记录 32 bytes、原有 installer 记录 60 bytes 和 SDK 跟踪字段
24 bytes 已链接；原有跟踪的 30 个 framework static object 不变。这不是全部
新增 SDK 静态开销或运行堆测量，分配后 internal/PSRAM/最大块仍待实机比较。

新增 `test_wifi_eap_radio.py` 使用生产 registry acquire/release、生命周期准入、
connection owner、EAP Radio install/clear/status 及 runtime prepare；SDK installer
作为注入边界，另有其生产实现 fixture。覆盖已连接/观察失败拒绝、部分安装失败、
固定 lease、旧 identity、dispatch 失败仍保留、APSTA、断连/复用屏障与清理重试。
Vendor fixture 增加可选实际 EAP 记录声明；core teardown fixture 增加 EAP 未排空
时仍禁止 VM 释放的场景。三份 fixture 仅 AST，未 import/编译/执行。
