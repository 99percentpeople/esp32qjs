# W-08 WPS 原始错误与接收端边界

接续 [retained worker](2026-09-11-w08-wps-worker.md)，本批在固定 SDK 的
build-local 生产路径接入初始化、扫描和 EAPOL 错误记录。公开 WPS API、
Radio/Station 恢复及事件交接仍未完成。

## 代码变化

- 托管操作保留第一个原始错误与阶段；错误立即撤销后续回调处理权限并清零
  尚未交付的 PIN/凭据。当前 SDK 调用栈仍使用的存储由 worker 后续清理，
  清理错误不覆盖原操作错误。
- 检查直接分配、MAC、设备信息、PIN、协议初始化、Probe/Association IE、
  callback 注册、timer、DH、断连、扫描提交/完成、配置、连接和 start flag。
  SDK 已丢失具体原因的协议初始化失败仍报告通用失败，不伪称精确 OOM。
- 扫描选中 AP 后，配置失败不再继续连接；连接失败不再启动后续等待。
  `failure_retry_cnt` 在提交配置之前写入。托管操作不启动 SDK 隐式旧 AP
  自动重连，旧 Station 配置须由尚待接入的外层 owner 恢复。
- 托管 EAPOL 接收检查协商阶段、选中 BSSID 和当前关联 BSSID。断连后的
  排队帧及无关 peer 被忽略；此检查不是 RF request cookie，也不证明重放隔离。
- RSN 解析失败不读取未初始化结果；移除可能非终止 SSID 的 `%s` 日志和
  完整接收包 dump。EAPOL 长度在窄化前检查，发送 buffer 和 WSC 临时数据
  使用清零释放；BSSID 查询与 TX 保留原始错误。
