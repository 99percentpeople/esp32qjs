## 实现和边界

- capabilities/configure/status 与 enable/disable/clear 一起受 Wi-Fi 和 SDK
  Enterprise gate 控制。三个控制注册原生 Future，没有新增占位 API 或 v2。
- configure 在任何 getter 前取修订号；严格生产 capture 构造独立 profile。
  getter 返回后再查 busy/closing/revision，避免等待另一控制的 SDK 锁；完整
  `{configured:true,revision}` 结果在 commit 前分配。revision 为十进制 uint64
  字符串，不经浮点数截断。分配失败或过期捕获释放候选，不覆盖当前配置。
- 控制 capture 先保留单配置 operation token/profile，start 在 runtime 任务
  检查 helper 状态并复制 lease 值。worker 只读取副本；Radio mutex 下重新验证
  精确 identity，worker 不读取可变 helper 指针。
- disable/clear 只在存在 Enterprise binding 时沿已有断连/epoch/reuse barrier
  收尾，不因仅有配置而断开另一个 PSK 连接。clear 仅在成功退休后释放配置，
  disable 保留配置。enable 不隐式 start/connect；成功不等于认证通过。
- 后台队列拒绝明确失败。worker 开始时观察取消；检查之后取消不能阻止后续 SDK
  进入，也不能撤销已发生副作用。Future deadline 可先结束公共结果；原生状态、
  token 和 profile 引用保留至 worker release-store done 后由 poll 收尾。关闭时
  Future core 排空与 config busy 门槛共同阻止提前销毁。
- 采用 background worker，done 是 worker 对状态的最后访问，返回后不向已经可
  释放的 runtime/Future 发 wake；周期 poll 不依赖观察事件队列容量。
- 忙时 status 不查询 Radio/SDK，binding/enabled/cleanupPending 报 null，native
  未观察。其他字段是非秘密配置/资源元数据；不记录凭据或凭据派生错误文本。
  结果转换 OOM 不撤销已经完成的 SDK 操作，调用方须读 status 决定下一步。
- 正常 binding 保留 scan/connect 操作槽；当前仍固定 helper owners、阻止
  stop/restart 和新 Radio owner。完整恢复与共存继续待实现，不能宣称已解决。

公共类型、API docs/catalog、实际 manifest 和 SDK map 同步。SDK map 对实际
调用的 setters/enable/disable 记为 reviewed/in-progress；host 未运行，故不标
implemented。未展开的其他高级能力仍 contract-pending。

镜像、编译对象/archive/ELF、已跟踪 SRAM 静态对象和源文件 hash 见

静态对象大小不变，这不替代运行堆/最大块测量。Feature 27、SDK schema
STA35/AP21、strict TypeScript、MQuickJS 61 sources / 59 doc snippets、SDK map
与 whitespace 检查通过。共享 SDK 源码未修改。

首次 ELF 证据检查发现 ROM table 主机生成器缺少 Enterprise gate：源 manifest
包含六个入口，但目标 ELF 不含 js_wifi_enterprise_*。已将该 SDK 开关纳入
MQUICKJS_HOST_CFLAGS；修复后的证据要求启用镜像六个符号全部链接、关闭镜像
全部不存在，避免仅以源注册或成功构建声称公开入口可用。

与 config/profile，仅注入 Radio/SDK 和队列边界；覆盖队列拒绝、启动前取消、
队列中取消、SDK 进入后迟到完成、断连等待、清理失败保留与重试、无 binding 的
PSK 保护和最终配置释放。仅 AST，未 import、编译或执行。
