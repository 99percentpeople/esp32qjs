## SDK 依据与契约

固定 esp_wifi_types_generic.h 仅定义 MASK_NONE=0、AP_PROBEREQRECVED=BIT(0)
和 MASK_ALL=0xffffffff；esp_wifi.h 说明置位事件不交付 system handler，默认屏蔽
probe request。因此公开 setter 仅接受整数 0/1，拒绝 ALL 及其他位，不把事件 ID
移位误当 SDK mask。保留内部控制事件是输入准入保证，不靠队列有剩余空间来保证。
getter 返回 SDK 完整 uint32，包括异常/外部写入的未知位，供诊断；不可直接视为
可安全重放值。观察订阅仍优先用 wifi.watch({events}) 的每订阅 filter。

## 生产实现

Radio 统一入口在 mutation mutex 下检查 initialized/stable started 或 stopped、
无 lifecycle/operation/fault/cleanup/restart。无隐式 init/owner/stop，SDK 不在 IRQ
critical 内执行。唯一可写位只影响 probe 观察，允许现有 RF owner、wake lock、
promiscuous/临时 rate obligation 和 watcher 共存，不把它们替换为新的控制 lease。
Radio event broker 管全局设置；它不是随 watcher.close 恢复的临时订阅配置。

先快照旧 mask；同值无写入返回。否则单次 SDK setter 后读回核对。失败时只重写
已知安全旧值并核对；原错误与 rollback 错误分别保留。旧值为 ALL/未知位时允许
显式安全替换，但失败绝不恢复旧危险值。未证实恢复时 fault Radio，回滚失败还
记录 event-mask-rollback 清理故障；无后台重试/自动恢复，现阶段需设备重启。
完整物理 restart 的状态重放仍在 W-07 总范围，不因新 setter 已注册而视为完成。

恢复配置值不能补发被屏蔽的事件或撤回已排队观察。解开 probe mask 可能增加流量，
复用既有 bounded watch ingress/队列/drop 账本，不宣称 lossless。内部控制状态和
Future 完成保持先于观察交付。该队列/真实任务竞争仍待集中验收。

共享 Driver write error converter 现在支持 interface=null，其余接口级 setter
保持原 station/access-point 值。新 API 复用 read/write error 以及 Radio.configuration，
普通读不覆盖前一次配置事务。JS 数值/错误分配失败不撤销已发生的 native 写入。
无新静态表、JS root、异步 job 或订阅恢复任务。
