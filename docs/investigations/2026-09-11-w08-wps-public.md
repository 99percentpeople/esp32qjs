# W-08 WPS 公开 Session、Future 与观察

本批接续原生 Session，公开 Station enrollee PBC/PIN：
`wifi.wps.capabilities/status/start`、`WiFiWpsSession.status/watch/receive/cancel/close`。
API、源类型、注册表、生成 manifest 和 runtime 接入保持唯一 v1；无 registrar
占位入口。AP registrar 是固定 SDK 已有而框架仍待实现的能力，继续保留任务。

选项在创建原生 Session 前全部校验；PIN 要求八位 ASCII 和校验和，省略或
00000000 表示 SDK 生成，PBC 禁止 PIN 选项。device 字段按 UTF-8 字节上限
复制并拒绝 NUL。JS handle 构造后才激活 Station 预留/后台协商，失败释放
精确 owner；SDK 接受仍为异步，不把 start 返回 handle 当作 RF 启动成功。

PIN 和最多三组凭据分别 copy/commit；完整 JS 转换成功才清零并消费原生副本。
SSID/password 使用原生显式长度，保留 NUL 和最大长度；auth/encryption 是
WPS 原始掩码，credential MAC 不冒充 AP BSSID。status/error/watch 只含元数据。

receive/close 复用生产 Future。receive 等待超时返回 null，取消只结束等待；
Session timeout 则撤销结果并关闭。SDK 自己固定 120 秒协商限制不会被 Session
预算扩展。cancel 同步请求关闭；close 等待所有原生/Radio/Station owner 退休。
close 开始后的等待取消/超时不终止原生清理；原生 storage 仍由 registry/worker
保留。转换失败、并发 receive 消费竞争及 Future 最后引用由生产路径负责。

watch 每 Session 一个、全局最多四个存活队列，容量 1..16，默认 8；drop-newest，
只记录最新采样语义状态，workerBusy 单独变化不生成事件。Future 结果观察门槛
复用 Session waiter；序号不回绕，队列满不参与控制完成。queue context 单独
持有预算直到实际释放，runtime 先关闭观察再排空 WPS 原生 Session。

新增 VM GC/Nth OOM 转换、Future callback/native retention 和 watch 饱和/
关闭/预算用例，均直接调用生产实现，边界注入范围记录在测试文件。仅 AST
解析，不导入、编译或执行 fixture；完整 Future core/RTOS/RF 仍待集中验证。

首轮启用 Wi-Fi 的四配置构建发现 class ID 增加而 JS_CLASS_COUNT 未增加，
导致生成类表越界；已同时修正运行侧与生成侧 class count。原始失败日志保留，
Wi-Fi-disabled 首轮通过。修正后的五配置生产构建/静态产物核对结果见后续记录。

未刷写、操作串口、提交、推送或更新根仓库 gitlink。完整安全、错误注入、
AP registrar 及其他 Wi-Fi 功能与运行/实机验收仍在总表，不缩小目标。

最终 C3、S3、C5 roaming、C5 no-SoftAP、C5 Wi-Fi-disabled 五配置生产构建
通过。公开 WPS binding、Future 注册、Station 预留和观察轮询已进入四种启用
配置的最终 ELF；disabled 的公开 adapter object 无定义/外部引用，ELF 无 WPS。
生成 SDK 源与 patcher 一致，公开/Session/worker object 与 archive member
一致；证据为 `build/w08-wps-public-evidence.json`，不代表运行测试通过。

manifest 为 55 classes / 538 functions；类型、文档、schema、SDK coverage、
MQuickJS（61 sources / 63 snippets）与 whitespace 检查通过。manifest 中
123 个 native Future 注册仍低于现有 128 上限；没有扩大常驻 Future 表。
