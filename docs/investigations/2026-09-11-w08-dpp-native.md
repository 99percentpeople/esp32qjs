# DPP 原生结果、排队任务与关闭

基线 firmware `d7db8d1`、固定 SDK `fff9895c82d744c7237be8847347bdd1b07c6643`。
本批延续 [bootstrap/配置事务](2026-09-11-w08-dpp-input.md)，实现内部原生命令与
结果保留；Radio/helper、worker、公开 Session/Future/watch 尚未接入。
所有 SDK 修补仍只进入 Build Context 对应的构建目录，共享 SDK 不修改。

## 原生交付

初始化前预留一个按需分配的有界结果对象，包含最多 1024 字节 URI 和当前
Build Context 的 `ESP_DPP_MAX_CONFIG_COUNT` 个完整凭据。身份为不回绕的 64-bit
整数；用尽明确失败。URI 和首个配置/失败终态先在原生对象保存，copy 成功后的
commit 才消费交付标记，转换失败不丢结果。配置交付后保留全部 row 供后续选择，
直到显式 release 清零释放；status 只含身份、计数、错误和清理元数据。

托管结果不向默认事件队列发送 URI 或凭据，也不自动安装第一条配置。普通 SDK
调用仍发布 Wi-Fi 事件，但改为零等待观察：发布失败计数，不撤销已经保存的
URI、配置终态或配置安装。SDK 自动安装与原生结果提交使用同一把 API mutex，
不再经过解锁后的配置指针/revision 比较窗口。首次终态不会被迟到失败覆盖。

内部 `esp32qjs_dpp_native_begin/bootstrap/listen/close` 已编码并使用精确身份；
托管 begin 的部分初始化失败仍返回需要清理的 identity。旧 SDK init/deinit/
bootstrap/listen 命令不能接管托管对象。DPP 与尚未 release 的 Station/AP WPS
结果互相排斥，不以 SDK heap 已释放推断配网 owner 已消失。未注册公开 DPP API。

## 排队与关闭

全部 DPP 非阻塞 eloop 调用改用最多 32 个按需记录；队列只持有不复用的数字
ticket，记录保留 handler、generation 和真正的参数 owner。取消已经从 eloop
取出的任务时，只使其失效并保留参数，直到 dispatch 丢弃；重复旧 ticket 不能
命中新记录。RX 从原生准入到排队都在 API mutex 内，关闭时归还被取消的 RX/
TX/ROC payload。bootstrap 仍通过自己的取消与清零路径释放含私钥的 job。

关闭按以下顺序执行，失败保留后缀并允许重试：

1. 关闭准入，拒绝在活动 DPP callback 内析构，取消 bootstrap 和全部排队任务。
2. 使用已记录的 Action/ROC owner 请求取消；固定 SDK ioctl 层在实际取消前
   检查 callback、接口、信道、secondary 和 op ID，不能取消其他模块的 owner。
   成功的取消步骤不重复，原始提交/取消错误分别保留。
3. 在原生 ioctl 执行点确认完整 off-channel record 清零。包括返回错误的提交，
   也保留这一检查义务；错误返回本身不证明没有 driver ownership。
4. 注销已成功注册的 TX/ROC listener。注销失败保留其登记和 SDK/result storage。
5. 零等待投递带本次 identity 的私有事件屏障，并等待默认事件循环确认。队列满
   或屏障未处理返回未完成，不能伪造已排空。随后注销屏障 listener。
6. 释放 SDK heap，托管结果另行 release；最后释放会清零 URI、凭据和整个对象。

SDK 初始化失败也进入这套关闭后缀。driver 调用和事件 listener 注销不在 CPU
临界区内；listener 注册/注销期间不持有 DPP API mutex。

## 验证边界

- 仅检查受影响的 C3 DPP 配置增量构建，日志/源码/实际 archive 的对应关系见
  `build/w08-dpp-native-evidence.json`。其他目标、功能关闭矩阵留到模块节点。
- 新增 `test_dpp_async_ownership.py`、`test_dpp_retained_results.py`，使用生产
  `.inc`、实际 SDK row 声明及受控 allocator/eloop/driver/event 边界，覆盖取出后
  取消、旧 ticket、满额、copy/commit、首终态、部分注销、队列满和精确屏障。
  原 bootstrap/config fixture 同步新边界。四份文件仅做 AST 检查，未导入、
  编译或执行测试 fixture。
- 当前是源码修复和生产构建证据；动态复现、真实调度、GC/OOM、RF 与实机均为
  `not-run`，不提升稳定等级。构建中的私有命令尚无 Radio/Session caller，
  archive 中存在函数不等于公开入口已交付。
